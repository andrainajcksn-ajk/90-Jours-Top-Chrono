# 90-Jours-Top-Chrono
Dépôt de code pour l'application de remise en forme "90 jours Top Chrono" par Andraina.

Bienvenue sur le dépôt de code pour l'Application "90 jours Top Chrono".
Cette application est destinée à accompagner tous les sportifs pour le maintien de leur forme, que ce soit forme 
physique ou sanitaire. Tout cela pendant 90 jours.

Elle prend en compte les exercices (musculation, courses, etc.), l'alimentation et l'hygiène de vie de chaque utilisateur.

Chaque utilisateur peut ajouter ses propres exercices à effectuer par jour, tout comme ses alimentations et son hygiène de vie. 
C'est à chaque utilisateur donc créer ses propres défis car le plus grand adversaire de chacun c'est soi-même.

*Ajout d'exercices : 
En entrant pour la première fois dans l'Appli, l'utilisateur peut voir un Chrono non lancé. Il y a un bouton pour ajouter des tâches,
exercices, etc.
